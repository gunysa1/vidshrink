# PC Worker (NVENC) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the user's Windows PC (RTX 2080) take encode jobs from the server with NVENC whenever the user switches it on, while the server stays the only machine that verifies and replaces originals.

**Architecture:** A job service on the server (stdlib `http.server`, token auth) wraps a `JobStore` that leases queued rows out of the existing SQLite DB. The PC worker claims a job, downloads it straight from Drive, encodes it with `hevc_nvenc`, runs the existing checks, uploads `<stem>.vidshrink-tmp.mkv` and reports. The server's existing worker loop verifies the upload on Drive and runs the existing swap. A tray app on Windows starts and stops the PC worker.

**Tech Stack:** Python 3.11+ stdlib on the server (`http.server`, `urllib`, `sqlite3`, `threading`, `secrets`, `tomllib`); on the PC also `pystray` + `Pillow` (optional extra `pc`). rclone, ffmpeg with `hevc_nvenc` and `libvmaf` on the PC. pytest.

**Spec:** `docs/superpowers/specs/2026-10-05-pc-worker-design.md`

## Global Constraints

- The server stays stdlib-only at runtime. `pystray`/`Pillow` are only in the optional `pc` extra and are imported inside the tray function only.
- Modules the PC imports (`paths`, `rclone`, `probe`, `verify`, `encode`, `scorer`, `db`, `config`, `jobs` client side, `pc_worker`, `calibrate`, `tray`) must not import `fcntl` or `worker`. `worker.py` stays server-only.
- New stages: `leased` and `remote_ready`. New columns: `worker` TEXT, `lease_until` REAL, `encoder` TEXT, `remote_md5` TEXT, added by migration on `db.connect`.
- Lease: 1800 s; heartbeat every 60 s.
- Only the server deletes or replaces originals. The PC may delete only its own `<stem>.vidshrink-tmp.mkv`, and only for a job it is abandoning, or after a `409` when the tmp's md5 equals its own output.
- Download budget is charged at claim (the source size); upload budget at report (`out_size`). These are the existing global budgets (500 GB/700 GB per Pacific day).
- NVENC is never given HDR sources (`probe.is_hdr`). Dolby Vision is already skipped by the scorer.
- Learned keys: x265 keeps the existing `ratio:<family>` / `speed:<res>`; NVENC uses `ratio:<family>:nvenc` / `speed:<res>:nvenc`. NVENC defaults: ratio = x265 default × 0.85; speed SD 0.05, 720p 0.08, 1080p 0.15, 4K 0.5.
- Server handover: skip queued rows with expected x265 encode time > 6 h (non-HDR) while the PC was seen within 3 days.
- PC rclone: `--bwlimit 6M:off` (uploads 6 MiB/s, downloads unthrottled) plus the server's pinned Drive flags.
- Job service: default `0.0.0.0:8765`, token in `~/vidshrink/serve.token` (mode 600), `Authorization: Bearer <token>`; anything else gets 401.
- Tests never touch `gdrive:` or a GPU: a local temp dir is the rclone remote, and the NVENC encode is replaced by libx265 `ultrafast` in tests.
- Run tests with `.venv/bin/pytest` from `~/vidshrink`. Every commit ends with the session's attribution trailer lines.

```python
def run_encode_cancellable(cmd: list[str], log_path: Path, cancel: threading.Event) -> float:
    start = time.monotonic()
    with open(log_path, "w") as log:
        proc = subprocess.Popen(cmd, stdout=log, stderr=subprocess.STDOUT)
        while True:
            try:
                code = proc.wait(timeout=1)
                break
            except subprocess.TimeoutExpired:
                if cancel.is_set():
                    proc.kill()
                    proc.wait()
                    raise EncodeCancelled("encode cancelled") from None
    if code != 0:
        tail = log_path.read_text(errors="replace")[-500:]
        raise EncodeError(f"ffmpeg exit {code}: {tail}")
    return time.monotonic() - start
```

```python
"""Leases encode jobs to remote workers (the PC). The server's DB stays the source of
truth; only the server verifies uploads and replaces originals."""
import json
import time
from collections.abc import Callable

from vidshrink import db, scorer
from vidshrink.budget import Budget
from vidshrink.config import Config
from vidshrink.paths import final_path, tmp_path
from vidshrink.probe import Probe
from vidshrink.rclone import Rclone, RcloneError

PC_SEEN_KEY = "pc_last_seen"
NO_WORK_RETRY_SECS = 600.0


class LeaseLost(Exception):
    """The job isn't leased by this worker any more (expired, released or cancelled)."""


class JobStore:
    def __init__(self, conn, cfg: Config, rclone: Rclone,
                 now: Callable[[], float] = time.time, log: Callable[[str], None] = print):
        self.conn = conn
        self.cfg = cfg
        self.rclone = rclone
        self.now = now
        self.log = log
        self.uploads = Budget(conn, cfg.daily_upload_limit, now)
        self.downloads = Budget(conn, cfg.daily_download_limit, now, kind="download")

    def _seen(self) -> None:
        db.kv_set(self.conn, PC_SEEN_KEY, str(self.now()))

    def _leased_by(self, job_id: int, worker: str):
        row = db.get(self.conn, job_id)
        if row is None or row["stage"] != "leased" or row["worker"] != worker:
            raise LeaseLost(f"job {job_id} is not leased by {worker}")
        return row

    def _candidates(self, encoder: str) -> list:
        scored = []
        for row in db.rows_in(self.conn, "queued"):
            probe = Probe.from_json(row["probe_json"])
            if probe.is_hdr:
                continue
            scored.append((scorer.encoder_score(self.conn, row["size"], probe, encoder), row))
        scored.sort(key=lambda t: (-t[0], t[1]["id"]))
        return [row for _, row in scored]

    def claim(self, worker: str, encoder: str = "nvenc") -> dict:
        self._seen()
        self.expire_leases()
        if self.downloads.blocked():
            return {"job": None, "retry_after": self.downloads.seconds_until_reset()}
        for row in self._candidates(encoder):
            final = final_path(row["path"])
            if final != row["path"] and self.rclone.exists(final):
                db.mark_if(self.conn, row["id"], ("queued",), "failed",
                           reason=f"target {final} already exists")
                continue
            if not self.downloads.allows(row["size"]):
                return {"job": None, "retry_after": self.downloads.seconds_until_reset()}
            with db.transaction(self.conn):
                taken = db.mark_if(self.conn, row["id"], ("queued",), "leased", worker=worker,
                                   encoder=encoder, final_path=final, reason=None,
                                   lease_until=self.now() + self.cfg.lease_secs)
                if taken:
                    self.downloads.add(row["size"])
            if not taken:
                continue
            self.log(f"leased to {worker}: {row['path']}")
            return {"job": {"id": row["id"], "path": row["path"], "size": row["size"],
                            "modtime": row["modtime"], "final_path": final,
                            "tmp_path": tmp_path(row["path"]),
                            "probe": json.loads(row["probe_json"])},
                    "retry_after": 0.0}
        return {"job": None, "retry_after": NO_WORK_RETRY_SECS}

    def heartbeat(self, job_id: int, worker: str) -> dict:
        self._seen()
        if not self._is_leased_by(job_id, worker):
            return {"cancel": True}
        db.mark_if(self.conn, job_id, ("leased",), "leased",
                   lease_until=self.now() + self.cfg.lease_secs)
        return {"cancel": False}

    def _is_leased_by(self, job_id: int, worker: str) -> bool:
        try:
            self._leased_by(job_id, worker)
            return True
        except LeaseLost:
            return False

    def report(self, job_id: int, worker: str, outcome: str, **data) -> None:
        self._seen()
        row = self._leased_by(job_id, worker)
        clear = {"worker": None, "lease_until": None}
        if outcome == "uploaded":
            db.mark(self.conn, job_id, "remote_ready", out_size=int(data["out_size"]),
                    out_md5=data["out_md5"], encode_secs=float(data["encode_secs"]),
                    reason=None, **clear)
            self.uploads.add(int(data["out_size"]))
        elif outcome == "failed":
            attempts = row["attempts"] + 1
            stage = "failed" if attempts >= self.cfg.max_attempts else "queued"
            db.mark(self.conn, job_id, stage, attempts=attempts,
                    reason=f"PC: {data.get('reason', '')}"[:500], **clear)
        elif outcome == "not_worth_it":
            db.mark(self.conn, job_id, "not_worth_it", reason=str(data.get("reason", ""))[:500],
                    **clear)
        elif outcome == "changed":
            db.mark(self.conn, job_id, "unprobed", reason="changed since scan",
                    probe_json=None, score=None, **clear)
        elif outcome == "download_quota":
            self.downloads.block(self.cfg.download_block_secs)
            db.mark(self.conn, job_id, "queued", **clear)
            self.log("PC hit Drive's download quota; downloads paused for everyone")
        else:
            raise ValueError(f"unknown outcome {outcome!r}")
        self.log(f"{worker} reported {outcome}: {row['path']}")

    def release(self, job_id: int, worker: str) -> None:
        self._seen()
        row = self._leased_by(job_id, worker)
        db.mark(self.conn, job_id, "queued", worker=None, lease_until=None)
        self.log(f"{worker} released: {row['path']}")

    def expire_leases(self) -> int:
        expired = self.conn.execute(
            "SELECT * FROM videos WHERE stage='leased' AND lease_until < ?", (self.now(),)
        ).fetchall()
        n = 0
        for row in expired:
            tmp = tmp_path(row["path"])
            try:
                if self.rclone.exists(tmp):
                    self.rclone.delete(tmp)
            except RcloneError as e:
                self.log(f"lease expired but {tmp} could not be removed yet: {e}")
                continue  # try again on the next sweep
            if db.mark_if(self.conn, row["id"], ("leased",), "queued", worker=None,
                          lease_until=None):
                n += 1
                self.log(f"lease expired ({row['worker']}): {row['path']}")
        return n
```

```python
class JobServiceError(Exception):
    pass


def load_or_create_token(path: Path) -> str:
    path = Path(path)
    if path.exists():
        return path.read_text().strip()
    path.parent.mkdir(parents=True, exist_ok=True)
    token = secrets.token_urlsafe(32)
    fd = os.open(path, os.O_WRONLY | os.O_CREAT | os.O_EXCL, 0o600)
    with os.fdopen(fd, "w") as f:
        f.write(token + "\n")
    return token


def make_server(store: JobStore, token: str, host: str, port: int) -> HTTPServer:
    expected = f"Bearer {token}".encode()

    class Handler(BaseHTTPRequestHandler):
        def log_message(self, fmt, *args):  # keep journald quiet; JobStore logs events
            pass

        def _send(self, code: int, body: dict) -> None:
            data = json.dumps(body).encode()
            self.send_response(code)
            self.send_header("Content-Type", "application/json")
            self.send_header("Content-Length", str(len(data)))
            self.end_headers()
            self.wfile.write(data)

        def _authorized(self) -> bool:
            got = self.headers.get("Authorization", "").encode()
            if hmac.compare_digest(got, expected):
                return True
            self._send(401, {"error": "unauthorized"})
            return False

        def do_GET(self):
            if not self._authorized():
                return
            if self.path == "/health":
                self._send(200, {"ok": True})
            else:
                self._send(404, {"error": "not found"})

        def do_POST(self):
            if not self._authorized():
                return
            try:
                length = int(self.headers.get("Content-Length", "0"))
                body = json.loads(self.rfile.read(length) or b"{}")
                if self.path == "/claim":
                    self._send(200, store.claim(body["worker"], body.get("encoder", "nvenc")))
                elif self.path == "/heartbeat":
                    self._send(200, store.heartbeat(int(body["id"]), body["worker"]))
                elif self.path == "/report":
                    extra = {k: v for k, v in body.items() if k not in ("id", "worker", "outcome")}
                    store.report(int(body["id"]), body["worker"], body["outcome"], **extra)
                    self._send(200, {"ok": True})
                elif self.path == "/release":
                    store.release(int(body["id"]), body["worker"])
                    self._send(200, {"ok": True})
                else:
                    self._send(404, {"error": "not found"})
            except LeaseLost as e:
                self._send(409, {"error": str(e)})
            except (KeyError, ValueError, TypeError, json.JSONDecodeError) as e:
                self._send(400, {"error": f"bad request: {e}"})
            except Exception as e:  # keep serving; the PC retries
                store.log(f"job service error on {self.path}: {e!r}")
                self._send(500, {"error": repr(e)})

    return HTTPServer((host, port), Handler)


class JobClient:
    def __init__(self, base_url: str, token: str, timeout: float = 30):
        self.base = base_url.rstrip("/")
        self.token = token
        self.timeout = timeout

    def _call(self, method: str, path: str, body: dict | None = None) -> dict:
        data = None if body is None else json.dumps(body).encode()
        req = urllib.request.Request(self.base + path, data=data, method=method, headers={
            "Authorization": f"Bearer {self.token}", "Content-Type": "application/json"})
        try:
            with urllib.request.urlopen(req, timeout=self.timeout) as resp:
                return json.loads(resp.read() or b"{}")
        except urllib.error.HTTPError as e:
            detail = e.read().decode(errors="replace")[:300]
            if e.code == 409:
                raise LeaseLost(detail) from None
            raise JobServiceError(f"HTTP {e.code} on {path}: {detail}") from None
        except (urllib.error.URLError, OSError) as e:
            raise JobServiceError(f"cannot reach job service at {self.base}: {e}") from None

    def health(self) -> dict:
        return self._call("GET", "/health")

    def claim(self, worker: str, encoder: str = "nvenc") -> dict:
        return self._call("POST", "/claim", {"worker": worker, "encoder": encoder})

    def heartbeat(self, job_id: int, worker: str) -> dict:
        return self._call("POST", "/heartbeat", {"id": job_id, "worker": worker})

    def report(self, job_id: int, worker: str, outcome: str, **data) -> None:
        self._call("POST", "/report", {"id": job_id, "worker": worker, "outcome": outcome, **data})

    def release(self, job_id: int, worker: str) -> None:
        self._call("POST", "/release", {"id": job_id, "worker": worker})
```

```python
"""The Windows PC's side: claim a job, encode it with NVENC, upload, report.
Must stay importable on Windows: no fcntl, no vidshrink.worker."""
import os
import platform
import threading
import time
import tomllib
from collections.abc import Callable
from dataclasses import dataclass, field, fields
from pathlib import Path

from vidshrink.config import Config
from vidshrink.encode import (EncodeCancelled, EncodeError, build_nvenc_command,
                              run_encode_cancellable)
from vidshrink.jobs import JobClient, JobServiceError, LeaseLost
from vidshrink.paths import md5_file
from vidshrink.probe import Probe, ProbeError, parse_ffprobe, run_ffprobe
from vidshrink.rclone import Rclone, RcloneError, with_retries
from vidshrink.verify import compare, decode_errors

TOOLS = ("rclone", "ffmpeg", "ffprobe")


def _default_workdir() -> Path:
    base = os.environ.get("LOCALAPPDATA") or str(Path.home() / ".cache")
    return Path(base) / "vidshrink" / "work"


@dataclass
class PCConfig:
    server: str
    token: str
    remote: str = "gdrive:"
    workdir: Path = field(default_factory=_default_workdir)
    cq: int = 23
    bwlimit: str = "6M"
    worker_name: str = field(default_factory=platform.node)
    rclone: str = "rclone"
    ffmpeg_dir: str = ""
    min_saving: float = 0.20
    heartbeat_secs: float = 60
    idle_secs: float = 300
    retry_attempts: int = 5
    retry_base_delay: float = 5.0


def default_config_path() -> Path:
    base = os.environ.get("APPDATA") or str(Path.home() / ".config")
    return Path(base) / "vidshrink" / "config.toml"


def load_pc_config(path: Path) -> PCConfig:
    data = tomllib.loads(Path(path).read_text())
    known = {f.name for f in fields(PCConfig)}
    unknown = set(data) - known
    if unknown:
        raise ValueError(f"unknown settings in {path}: {sorted(unknown)}")
    if "workdir" in data:
        data["workdir"] = Path(data["workdir"])
    return PCConfig(**data)


def pc_rclone(cfg: PCConfig) -> Rclone:
    # Same pinned Drive behaviour as the server, plus an upload-only bandwidth cap so the
    # 100 Mbps uplink stays usable for Plex.
    return Rclone(cfg.remote, (*Config().rclone_args, "--bwlimit", f"{cfg.bwlimit}:off"),
                  binary=cfg.rclone)


class _Abandon(Exception):
    """Stop working on the current job (Stop now or the server cancelled it)."""


EncodeFn = Callable[[Path, Path, Probe, Path, threading.Event], float]


class PCWorker:
    def __init__(self, cfg: PCConfig, client: JobClient, rclone: Rclone,
                 encode: EncodeFn | None = None, log: Callable[[str], None] = print):
        self.cfg = cfg
        self.client = client
        self.rclone = rclone
        self.encode = encode or self._nvenc
        self.log = log
        self.state = "idle"
        self.stage = ""
        self.current_path: str | None = None
        self.done = 0
        self._stop_now = threading.Event()
        self._stop_after = threading.Event()
        self._cancel = threading.Event()  # current job only
        if cfg.ffmpeg_dir:
            os.environ["PATH"] = cfg.ffmpeg_dir + os.pathsep + os.environ.get("PATH", "")

    # --- control -------------------------------------------------------------
    def stop(self, now: bool) -> None:
        if now:
            self._stop_now.set()
            self._cancel.set()
        else:
            self._stop_after.set()
            if self.state == "working":
                self.state = "finishing"

    def _check(self) -> None:
        if self._cancel.is_set():
            raise _Abandon()

    # --- loop ---------------------------------------------------------------
    def run(self) -> None:
        self.cfg.workdir.mkdir(parents=True, exist_ok=True)
        try:
            while not self._stop_now.is_set() and not self._stop_after.is_set():
                try:
                    resp = self.client.claim(self.cfg.worker_name, "nvenc")
                except JobServiceError as e:
                    self.log(f"job service unreachable, retrying: {e}")
                    self._stop_now.wait(self.cfg.idle_secs)
                    continue
                job = resp.get("job")
                if job is None:
                    self.stage = "waiting for work"
                    self._stop_now.wait(min(resp.get("retry_after") or self.cfg.idle_secs,
                                            self.cfg.idle_secs))
                    continue
                self.state = "finishing" if self._stop_after.is_set() else "working"
                self._do_job(job)
                self.state = "idle"
        finally:
            self.state = "stopped"
            self.stage = ""

    def _retry(self, fn):
        return with_retries(fn, self.cfg.retry_attempts, self.cfg.retry_base_delay,
                            lambda s: self._stop_now.wait(s))

    def _heartbeat(self, job_id: int, stop: threading.Event) -> None:
        while not stop.wait(self.cfg.heartbeat_secs):
            try:
                if self.client.heartbeat(job_id, self.cfg.worker_name).get("cancel"):
                    self.log("server cancelled the job")
                    self._cancel.set()
                    return
            except JobServiceError as e:
                self.log(f"heartbeat failed (will retry): {e}")

    def _nvenc(self, src: Path, out: Path, probe: Probe, log_path: Path,
               cancel: threading.Event) -> float:
        return run_encode_cancellable(build_nvenc_command(src, out, probe, self.cfg.cq),
                                      log_path, cancel)

    def _report(self, job: dict, outcome: str, **data) -> None:
        try:
            self.client.report(job["id"], self.cfg.worker_name, outcome, **data)
        except LeaseLost:
            self.log(f"lease lost before reporting {outcome}: {job['path']}")

    def _do_job(self, job: dict) -> None:
        self._cancel.clear()
        if self._stop_now.is_set():
            self._cancel.set()
        jid, path, tmp = job["id"], job["path"], job["tmp_path"]
        src = self.cfg.workdir / f"{jid}.src"
        out = self.cfg.workdir / f"{jid}.out.mkv"
        log_path = self.cfg.workdir / f"{jid}.log"
        probe = Probe(**job["probe"])
        self.current_path = path
        hb_stop = threading.Event()
        hb = threading.Thread(target=self._heartbeat, args=(jid, hb_stop), daemon=True)
        hb.start()
        uploading = False
        md5 = None
        try:
            self.stage = "downloading"
            self._check()
            self._retry(lambda: self.rclone.download(path, src))
            self._check()
            if src.stat().st_size != job["size"]:
                self._report(job, "changed")
                return
            self.stage = "encoding"
            secs = self.encode(src, out, probe, log_path, self._cancel)
            self.stage = "verifying"
            out_size = out.stat().st_size
            verdict = compare(probe, parse_ffprobe(run_ffprobe(str(out)), out_size),
                              job["size"], out_size, self.cfg.min_saving, decode_errors(out))
            if verdict.problems:
                self._report(job, "failed", reason="; ".join(verdict.problems))
                return
            if verdict.not_worth_it:
                self._report(job, "not_worth_it",
                             reason=f"only {1 - out_size / job['size']:.0%} smaller")
                return
            md5 = md5_file(out)
            self._check()
            self.stage = "uploading"
            uploading = True
            self._retry(lambda: self.rclone.upload(out, tmp))
            if self.rclone.md5(tmp) != md5:
                self.rclone.delete(tmp)
                self._report(job, "failed", reason="checksum mismatch after upload")
                return
            self._check()
            try:
                self.client.report(jid, self.cfg.worker_name, "uploaded", out_size=out_size,
                                   out_md5=md5, encode_secs=secs)
                self.done += 1
                self.log(f"uploaded {tmp} ({out_size / 1e9:.1f} GB)")
            except LeaseLost:
                self._delete_tmp_if_ours(tmp, md5)
        except (_Abandon, EncodeCancelled):
            self._abandon(job, tmp if uploading else None, md5)
        except RcloneError as e:
            if e.download_quota:
                self._report(job, "download_quota")
            else:
                self._report(job, "failed", reason=str(e))
        except FileNotFoundError as e:
            if Path(str(e.filename)).stem.lower() in TOOLS:
                self._abandon(job, None, None)
                raise
            self._report(job, "failed", reason=str(e))
        except (EncodeError, ProbeError, OSError) as e:
            self._report(job, "failed", reason=str(e))
        finally:
            hb_stop.set()
            hb.join(5)
            for f in (src, out, log_path):
                f.unlink(missing_ok=True)
            self.current_path = None
            self.stage = ""

    def _delete_tmp_if_ours(self, tmp: str, md5: str | None) -> None:
        try:
            if md5 and self.rclone.exists(tmp) and self.rclone.md5(tmp) == md5:
                self.rclone.delete(tmp)
        except RcloneError as e:
            self.log(f"could not remove {tmp}: {e}")

    def _abandon(self, job: dict, tmp: str | None, md5: str | None) -> None:
        # While the job is still leased to us nobody else writes this tmp name, so a
        # partial upload can be removed without an md5 check.
        if tmp:
            try:
                if self.rclone.exists(tmp):
                    self.rclone.delete(tmp)
            except RcloneError as e:
                self.log(f"could not remove partial {tmp}: {e}")
        try:
            self.client.release(job["id"], self.cfg.worker_name)
        except (LeaseLost, JobServiceError):
            pass
        self.log(f"abandoned: {job['path']}")
```

```python
"""Pick the NVENC CQ that matches the server's x265 CRF 22 picture quality (VMAF)."""
import json
import subprocess
import tempfile
import threading
from collections.abc import Callable
from pathlib import Path
from statistics import mean

from vidshrink.encode import EncodeError
from vidshrink.probe import Probe


def vmaf(distorted: Path, reference: Path, threads: int = 4) -> float:
    with tempfile.TemporaryDirectory() as d:
        log = Path(d) / "vmaf.json"
        graph = ("[0:v]format=yuv420p10le,setpts=PTS-STARTPTS[d];"
                 "[1:v]format=yuv420p10le,setpts=PTS-STARTPTS[r];"
                 f"[d][r]libvmaf=n_threads={threads}:log_fmt=json:log_path={log.as_posix()}")
        res = subprocess.run(["ffmpeg", "-hide_banner", "-nostdin", "-v", "error",
                              "-i", str(distorted), "-i", str(reference),
                              "-lavfi", graph, "-f", "null", "-"],
                             capture_output=True, text=True)
        if res.returncode != 0:
            raise EncodeError(f"vmaf failed: {res.stderr[-300:]}")
        return float(json.loads(log.read_text())["pooled_metrics"]["vmaf"]["mean"])


def cut_sample(src: Path, out: Path, probe: Probe, seconds: int = 60) -> None:
    start = max(0.0, probe.duration / 2 - seconds / 2)
    res = subprocess.run(["ffmpeg", "-hide_banner", "-nostdin", "-y", "-v", "error",
                          "-ss", f"{start:.1f}", "-i", str(src), "-t", str(seconds),
                          "-map", f"0:v:{probe.video_index}", "-c", "copy", str(out)],
                         capture_output=True, text=True)
    if res.returncode != 0:
        raise EncodeError(f"cut failed: {res.stderr[-300:]}")


def measure(samples: list[tuple[Path, Probe]], cqs: list[int],
            encode_nvenc: Callable[[int], Callable], encode_x265: Callable, workdir: Path,
            log: Callable[[str], None] = print) -> list[dict]:
    rows = []
    never = threading.Event()
    for src, probe in samples:
        name = src.stem
        sample_probe = Probe(**{**probe.__dict__, "video_index": 0, "streams": []})
        runs = [("x265", None, encode_x265)] + [("nvenc", cq, encode_nvenc(cq)) for cq in cqs]
        for encoder, cq, fn in runs:
            out = workdir / f"cal-{name}-{encoder}-{cq}.mkv"
            fn(src, out, sample_probe, workdir / "cal.log", never)
            score = vmaf(out, src)
            rows.append({"sample": name, "encoder": encoder, "cq": cq, "vmaf": score,
                         "size": out.stat().st_size})
            log(f"{name}: {encoder} {'' if cq is None else f'CQ {cq} '}VMAF {score:.2f}, "
                f"{out.stat().st_size / 1e6:.0f} MB")
            out.unlink(missing_ok=True)
    return rows


def pick_cq(rows: list[dict], tolerance: float = 0.5) -> int:
    target = mean(r["vmaf"] for r in rows if r["encoder"] == "x265") - tolerance
    by_cq: dict[int, list[float]] = {}
    for r in rows:
        if r["encoder"] == "nvenc":
            by_cq.setdefault(r["cq"], []).append(r["vmaf"])
    good = [cq for cq, v in by_cq.items() if mean(v) >= target]
    return max(good) if good else min(by_cq)


def format_table(rows: list[dict]) -> str:
    lines = [f"{'sample':<30} {'encoder':<7} {'CQ':>3} {'VMAF':>6} {'MB':>7}"]
    for r in rows:
        cq = "" if r["cq"] is None else str(r["cq"])
        lines.append(f"{r['sample'][:30]:<30} {r['encoder']:<7} {cq:>3} {r['vmaf']:6.2f} "
                     f"{r['size'] / 1e6:7.1f}")
    return "\n".join(lines)
```

```python
"""Tray icon for the PC worker: Start / Stop now / Stop after this file / Status / Exit."""
import atexit
import threading
from collections.abc import Callable

COLORS = {"off": (128, 128, 128), "working": (40, 170, 70), "finishing": (230, 160, 30)}


class TrayController:
    def __init__(self, make_worker: Callable):
        self.make_worker = make_worker
        self.worker = None
        self.thread: threading.Thread | None = None
        self.session_done = 0

    @property
    def state(self) -> str:
        if self.thread is None or not self.thread.is_alive():
            return "off"
        return "finishing" if self.worker.state == "finishing" else "working"

    def start(self) -> None:
        if self.state != "off":
            return
        self.worker = self.make_worker()
        self.thread = threading.Thread(target=self.worker.run, daemon=True)
        self.thread.start()

    def stop_now(self) -> None:
        if self.worker is not None:
            self.worker.stop(now=True)

    def stop_after(self) -> None:
        if self.worker is not None and self.state != "off":
            self.worker.stop(now=False)

    def shutdown(self) -> None:
        self.stop_now()
        if self.thread is not None:
            self.thread.join(30)

    def status_text(self) -> str:
        if self.state == "off":
            done = self.worker.done if self.worker else 0
            return f"Off — {done} file(s) this session"
        w = self.worker
        current = w.current_path.rsplit("/", 1)[-1] if w.current_path else "—"
        return f"{self.state.title()}: {w.stage or 'waiting'} — {current} ({w.done} done)"


def _icon_image(color):
    from PIL import Image, ImageDraw
    img = Image.new("RGBA", (64, 64), (0, 0, 0, 0))
    ImageDraw.Draw(img).ellipse((6, 6, 58, 58), fill=color + (255,))
    return img


def run_tray(controller: TrayController, title: str = "vidshrink") -> None:
    import pystray

    def refresh(icon):
        icon.icon = _icon_image(COLORS[controller.state])
        icon.title = f"{title}: {controller.status_text()}"
        icon.update_menu()

    def act(fn):
        def handler(icon, item):
            fn()
            refresh(icon)
        return handler

    stopped = threading.Event()

    def on_exit(icon, item):
        stopped.set()
        controller.shutdown()
        icon.stop()

    menu = pystray.Menu(
        pystray.MenuItem(lambda item: controller.status_text(), None, enabled=False),
        pystray.MenuItem("Start", act(controller.start),
                         enabled=lambda item: controller.state == "off"),
        pystray.MenuItem("Stop now", act(controller.stop_now),
                         enabled=lambda item: controller.state != "off"),
        pystray.MenuItem("Stop after this file", act(controller.stop_after),
                         enabled=lambda item: controller.state == "working"),
        pystray.MenuItem("Exit", on_exit),
    )
    icon = pystray.Icon("vidshrink", _icon_image(COLORS["off"]), title, menu)
    atexit.register(controller.shutdown)  # best effort on logoff; lease expiry covers the rest

    def setup(i):
        i.visible = True

        def ticker():
            while not stopped.wait(5):
                refresh(i)
        threading.Thread(target=ticker, daemon=True).start()

    icon.run(setup=setup)
```

```python
        for job in jobs:
            try:
                client.release(job["id"], pcfg.worker_name)
            except Exception:
                pass
        for sample, _ in samples:
            sample.unlink(missing_ok=True)
    return 0
```
